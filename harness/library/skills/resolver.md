# Resolver

Pick the skill that matches the input. Each line is: `- skill-name: when to use it`.

- meeting-actions: the input is a meeting transcript or long meeting notes containing several discussion points, and the task is to find and record the action items
- single-action: the input is a short typed instruction to add ONE action (e.g. "add an action for Sam to send the SOW by Friday"), even if some details like the owner or date are missing
